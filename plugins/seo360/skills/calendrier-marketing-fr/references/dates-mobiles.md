# Dates calculées 2026-2032

Lire ce fichier quand la CLI (`node "${CLAUDE_SKILL_DIR}/../../seo/cli.mjs" calendrier <année>`) n'est pas disponible. Les tables sont calculées par script (algorithme grégorien de Pâques et règles ci-dessous), comme la CLI. Au-delà de 2032, appliquer les règles.

## Règles de calcul

| Date | Règle |
|---|---|
| Pâques | Algorithme grégorien (calcul du comput) |
| Vendredi saint | Pâques − 2 jours (férié en Alsace-Moselle : Bas-Rhin, Haut-Rhin, Moselle) |
| Lundi de Pâques | Pâques + 1 |
| Ascension | Pâques + 39 (toujours un jeudi, donc pont le vendredi) |
| Pentecôte / lundi de Pentecôte | Pâques + 49 / + 50 (le lundi peut être la journée de solidarité : ouverture variable) |
| Fête des mères | Dernier dimanche de mai ; premier dimanche de juin si ce dimanche est la Pentecôte |
| Fête des pères | 3e dimanche de juin |
| Fête des grands-mères | 1er dimanche de mars (fête commerciale) |
| Soldes d'hiver | 2e mercredi de janvier, avancé au 1er mercredi si le 2e tombe après le 12 ; durée 4 semaines |
| Soldes d'été | Dernier mercredi de juin, avancé à l'avant-dernier si le dernier tombe après le 28 ; durée 4 semaines |
| Beaujolais nouveau | 3e jeudi de novembre |
| Black Friday / Cyber Monday | Lendemain / lundi suivant du 4e jeudi de novembre |

Soldes : règle nationale. Les départements dérogatoires et les dates officielles de l'année sont à confirmer sur economie.gouv.fr.

## Outre-mer

Chaque territoire a un jour férié pour l'abolition de l'esclavage : Mayotte 27 avril, Martinique 22 mai, Guadeloupe 27 mai, Guyane 10 juin, La Réunion 20 décembre. Ces dates sont à vérifier sur service-public.fr avant publication.
