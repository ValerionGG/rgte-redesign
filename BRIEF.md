## Règles de format .dc.html (obligatoires — échouent en silence)
Squelette exact :
```html
<!doctype html>
<html lang="fr">
<head>
<meta charset="utf-8">
<title>Vitrine — Accueil</title>
<script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=...&display=swap">
<style>
body{margin:0}
/* classes : hover, @keyframes, @media, :focus-visible */
</style>
</helmet>
<div style="... root fluide ...">…</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1440,"height":5200},"accent":{"editor":"color","default":"#D42A20","options":["#D42A20","#1A1A1A","#B08D57"]}}'>
class Component extends DCLogic {
  constructor(props){ super(props); this.state = { ligne: 'stone' }; }
  renderVals() { return { ... }; }
}
</script>
</body>
</html>
```
- Ligne `<script src="./support.js"></script>` EXACTE. Fermer tous les éléments non-void ; guillemets sur tous les attributs.
- PAGE fluide : root sans largeur px ; conteneurs `max-width` + padding latéral ; grilles `repeat(auto-fit, minmax(min(280px, 100%), 1fr))` ; hauteurs en px/rem (jamais `%`, pas de `vh`) ; nav qui se replie sur mobile (@media dans helmet). Les très grands titres : taille en `clamp()` qui tient dans la largeur (vérifier mentalement la longueur des mots à 1440 et 390 px), `overflow-wrap:anywhere` en secours.
- `{{trou}}` = lecture à points UNIQUEMENT (`{{item.prix}}`, `{{$index}}`), jamais d'expression (`{{!x}}`, `{{a+b}}`, `{{fn()}}` échouent). Tout calculer dans `renderVals()`.
- Événements : `onClick="{{ pick }}"`, `onInput="{{ setLen }}"`, `onChange` pour les select ; handler par élément : `items: xs.map(x => ({...x, pick: () => this.setState({sel:x.id})}))` puis `onClick="{{ item.pick }}"`. Les handlers de formulaire font `e.preventDefault()` si `onSubmit`.
- `<sc-if value="{{ cond }}" hint-placeholder-val="{{ true }}">…</sc-if>` (pas de else : deux drapeaux calculés). `<sc-for list="{{ items }}" as="item" hint-placeholder-count="3">…</sc-for>`. Ne PAS mettre `<sc-for>`/`<sc-if>` directement dans un `<select>`, `<table>`, `<tr>`, `<ul>` (options/lignes écrites en dur, ou structure en div).
- Styles variables selon l'état : chaîne pré-calculée (ex. `item.tabStyle`) liée par `style="{{ item.tabStyle }}"` ; les tokens statiques restent inline en dur.
- Classes CSS dans `<helmet><style>` pour hover, animations (@keyframes : révélations clip-path/translate, ken-burns, marquee, fondu), @media, `:focus-visible`. `url()` d'image seulement dans helmet (`url(assets/xxx.webp)`), jamais dans `style="…"` inline (préférer `<img>` + object-fit).
- Aucun réseau sauf Google Fonts css2 `<link>` et les `assets/…` ci-dessus. Pas d'`<iframe>`, `<object>`, `<embed>`, `innerHTML`, `appendChild`, `window.X`, écouteurs keydown globaux, imports, `setInterval` non nettoyé. JS classique.
- Icônes : SVG inline au trait, jamais d'emoji. Boutons icône seule avec `aria-label`. Vrais contrôles (`<button type="button">`, `<a href>`, `<input>`+`<label>`). Cibles ≥ 44 px. Contraste texte ≥ 4,5:1.
- `data-props` : `$preview` + 1 à 3 réglages, TOUJOURS au format descripteur `{"editor":"color"|"boolean"|"range"|"enum", "default":…}` (jamais une valeur nue). Le texte reste littéral dans le markup ; les données répétées (lignes, modules, secteurs, réalisations) dans renderVals.
- Pas d'Inter, Roboto, Arial, Fraunces. Pas de dégradés « IA » génériques, cartes à bordure gauche colorée, emoji. Aucune statistique inventée (« 30 ans d'expérience », « 500 clients ») : uniquement les faits du brief (5 lignes, 13 secteurs, 14 réalisations, 6 longueurs, températures, 5 800 € HT…) ou un marqueur [N].
- Interactivité réelle et riche sur chaque page (elle est évaluée) : survols élégants, animations d'entrée CSS, transitions, états sélectionnés.
